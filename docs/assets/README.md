# Demo assets

The root README includes these owner-supplied Telegram lesson captures, preserved
unchanged from the supplied PNG files:

- `telegram-lesson-attention.png` — *Attention Is All You Need* lesson after title
  search and `/choose 1`, with Egyptian-Arabic explanations and source page references.
- `telegram-lesson-rag.png` — *Retrieval-Augmented Generation for Knowledge-Intensive
  NLP Tasks* lesson selected with `/paper 2005.11401v4`, with source page references.

Both are lesson captures, not `/notes`, follow-up, or original-quotation examples.
The unused SVG files are retained as explicitly labelled placeholders, not captures.
The PNG metadata contains only standard sRGB, gamma, and DPI fields. The visible
content was reviewed for the restrictions below; this is not a general privacy audit.

Before adding other captures, review their full image and metadata. Do not include
private messages, personal account details, invite codes, tokens,
local paths containing private information, or the private benchmark paper's text
or questions. Prefer PNG or WebP screenshots at a readable phone aspect ratio.
