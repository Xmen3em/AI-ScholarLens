# Bounded development smoke scope

Authorized by the owner's 17 October request to research and implement, including
ordinary development verification. This is independent of every historical
evaluation grant. It cannot resume or spend any of their unused allowances.

One durable ceiling: **12 outbound model attempts**, including errors and unknown
outcomes, shared across text teaching, optional tool use and OCR. Store:
`data/study/smoke.sqlite3`, owner `development-smoke-20261017`. The ceiling cannot
be changed or reset by `/forget`. Repeated case IDs return existing results.
No automatic retry or inference fallback. Stop and inspect a failed case before
running a different diagnosis. No batch evaluation or acceptance claim.

Cases: first lesson on arXiv `2005.11401v4` (RAG); an Arabic follow-up; an unsupported
paper question; optional restricted Deep Agents tool flow (up to four of the same
12 attempts); one rendered public first page for LightOnOCR-2-1B/Featherless.
Title resolution and public metadata/source downloads do not invoke a model.
All model attempts reserve before the outbound request. No Telegram test message
is sent, no private paper uploaded, no new provider subscription/GPU allocated.

Inspect JSON shape, usage, citation equality, page/version identity, natural
Egyptian wording, coverage, numerical context and missing-evidence behavior.
An OCR route error leaves that route disabled. These are inspected development
examples, not an unseen benchmark or proof of translation/teaching accuracy.
